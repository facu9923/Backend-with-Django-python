# 🐍 Backend con Django
Este proyecto está diseñado para practicar los fundamentos de Django utilizando Python. A través de este backend, podrás aprender a manejar rutas, vistas, modelos y configuraciones básicas de Django.

# 🚀 Tecnologías utilizadas
- 🐍 Python – Lenguaje de programación principal.
- 🎯 Django – Framework web para el desarrollo del backend.
- 🗄️ SQLite / PostgreSQL – Base de datos para almacenar la información.
- 🔹 Virtualenv – Entorno virtual para gestionar dependencias.
